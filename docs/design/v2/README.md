# Design v2 — экраны и компоненты

Снимок холста [Budget App v2 — экраны и компоненты](https://claude.ai/artifact/2Gs2Zysg4pzHevT6tqMJ8b) от 2026-09-28.
Основной источник — сам холст; эти файлы — копия для истории и ревью.

- `canvas.json` — раскладка холста: доски, страницы «Экраны» и «Компоненты», заметки.
- `*.dc.html` — по файлу на доску: экраны телефона (390×844) и доски `Foundations`, `ComponentsCore`, `ComponentsLists`.

Локально файлы не отрисуются: они подключают `./support.js` редактора холста, а иконки категорий
грузят из хранилища артефакта (`/_blob/…`; исходники — `src/assets/icons/*.png`).
Токены совпадают с `src/assets/theme/tokens.css`, описание системы — `docs/design-system.md`.

Папка исключена из Prettier (`.prettierignore`), чтобы файлы оставались байт-в-байт как на холсте.
